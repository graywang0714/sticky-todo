# Sticky Notes

Windows 桌面浮窗 + Android 原生 App，用来快速记录待办和随笔。支持本地离线保存，也可以连接**你自己的 Supabase 项目**进行账号同步。

- **Windows**：Electron + React，自带界面资源，包含透明浮窗和完整版窗口。
- **Android**：Kotlin + Jetpack Compose + Room 原生界面，不使用 WebView。
- **Web**：React + Vite，可运行本地开发界面。
- **iOS**：目前未实现。

本次开源基线：Windows **1.9.0**、Android **0.6.0**。仓库提供源码和构建方法，不提供作者的云服务、用户数据或私人签名。名称为 **Sticky Notes**；GitHub 仓库地址保留为 `graywang0714/sticky-todo`。

## 功能

| 功能 | Windows | Android |
| --- | --- | --- |
| 待办新增、编辑、完成、撤销完成和历史回顾 | 支持 | 支持 |
| 随笔标题、正文、置顶和编辑 | 支持 | 支持行内编辑 |
| 拖动排序及相邻条目动态让位 | 圆点 / 图钉作为拖动手柄 | 长按条目拖动 |
| 置顶与普通记录分别排序 | 支持 | 支持 |
| 背景色、文字色、背景透明度 | 浮窗支持 | 沿用移动端布局 |
| 回收站：保留本机删除记录 30 天 | 支持 | 支持 |
| 邮箱验证码注册、密码登录及找回密码 | 支持 | 支持 |
| 离线修改、同账号恢复同步、账号间本机数据隔离 | 支持 | 支持 |

### 同步范围和限制

- 两端连接**同一个 Supabase 项目、登录同一个账号**，才能同步待办与随笔。
- 待办顺序随记录同步；**随笔手动顺序只在本机按账号保存**，Windows 的浮窗和完整版共用顺序。
- **回收站不跨设备同步**。在哪台设备删除，就在哪台设备恢复；恢复后的记录作为新的正常记录参与同步。30 天按删除时间计算，应用关闭时不能清理，恢复运行后清理到期内容。
- 云账号与“本机笔记本”分开保存，不会自动把本机模式的内容并入云账号。
- 实时连接可用时会接收变更，断线后重新核对。速度受网络、服务状态和操作系统后台限制影响，**不承诺锁屏后台永久在线或固定延迟**。
- Android 遇到无法安全合并的编辑，会保留手机版本到“冲突备份”；这不是完整版本历史。Windows 在导入旧缓存或远端记录已删除时，也可能生成保留副本。
- 离线冲突仍有边界：没有服务端版本历史或全局删除墓碑，不保证任意旧客户端组合下所有冲突自动合并。请先用测试数据验证自己的部署，再迁移重要内容。
- 这是正在迭代的个人工具；有账号隔离与客户端检查不等于已做独立安全审计。服务端必须启用正确的 RLS。

## 如何使用

### Windows

构建完成后双击便携 EXE，会打开待办和随笔两个浮窗，并出现托盘图标。

1. 点击空白处或 **＋** 记一条待办，回车保存。
2. **圆点 / 图钉只用于排序，不会完成任务**。按住它上下拖动，同组条目在松手前让位，松手保存顺序。
3. 绿色勾表示完成，橙色图钉表示置顶或取消置顶，红叉将记录移到本机回收站。
4. 点 **Todo / Done** 查看未完成或已完成记录；Done 中可恢复为未完成。
5. 右键浮窗或托盘 → **浮窗外观…**，调整背景色、文字色和透明度。透明度仅影响底板，文字仍清晰。
6. 托盘 → **打开完整版**，可使用账号、云同步设置和回收站。**Ctrl+Alt+G** 显示或隐藏浮窗；“窗口置顶”与单条待办置顶是不同功能。
7. 更新同一发行版时，从托盘退出程序后打开新 EXE；不需要清空用户数据或先退出账号。

### Android

1. 安装自己构建并签名的 APK，打开后可以在本机笔记本记事。
2. **记下**新增待办，点击条目文字在卡片内编辑，点保存完成编辑。
3. 右滑显示完成按钮；左滑显示置顶和删除。反向回滑或点空白可收起操作栏。
4. 长按待办或随笔上下拖动，同组内排序；松手前其他条目动态让位。圆点本身不会完成待办。
5. 点右上角账号图标登录或注册；同步状态在标题下方，垃圾桶图标打开回收站。
6. 升级时必须保持同一个应用 ID 和签名密钥，直接覆盖安装。换签名无法覆盖旧安装，卸载会删除本地数据。

### 注册、登录和忘记密码

- **注册**：输入邮箱 → 发送验证邮件 → 在应用中输入验证码 → 设置密码。需要后台邮件服务正常且模板包含验证码。
- **已有账号**：使用邮箱和密码直接登录；退出隐藏该账号数据，未同步操作保留在它自己的本机空间。
- **忘记密码**：输入邮箱 → 发送恢复邮件 → 输入最新验证码和新密码。验证码已通过但密码与原密码相同时，会明确提示直接登录。
- 推荐让邮件显示数字验证码。也支持将未打开的本项目验证链接粘贴进应用；Android 可解析 Gmail 包装链接。不要将验证码、恢复链接或密码发到 issue。
- 注册验证和密码找回流程不同，不要混用验证码。邮箱地址、验证码和新密码要对应当前这次操作。

## 本地运行 Web

需要 Node.js 22.12+（建议 22 LTS）和 npm：

```sh
git clone https://github.com/graywang0714/sticky-todo.git
cd sticky-todo
npm ci
npm run dev
```

终端会显示本地地址，默认端口 3000。未配置云服务时使用本机模式；需要同步时复制 `.env.example` 为 `.env.local`，填入自己的项目 URL 和客户端公开 key 后重启开发服务。
