# Sticky Notes 账号流程

请先按 [Supabase 配置说明](../docs/SUPABASE.md) 配好后台与验证码邮件。

- 注册：邮箱 → 发验证邮件 → 验证码 → 设置密码。
- 登录：同一个 Supabase 项目下的账号邮箱与密码。
- 找回：邮箱 → 最新恢复验证码 → 新密码。密码与原密码相同会提示直接登录。
- 退出：回到本机笔记本，不删除原账号的未同步编辑。
- 冲突备份：两端修改不能安全合并时保存手机内容；它不是云端版本历史。

默认邮件链接必须是同一项目且用途正确的未使用链接；Google / Gmail 的包装链接只在本机解析，不会访问外层 URL。不接受未知项目的恢复链接。推荐直接使用验证码，避免浏览器重定向问题。
